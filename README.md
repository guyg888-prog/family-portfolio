# תיק המשפחה

דשבורד מעקב אחזקות לשלושה אחים. מארק מנהל, רון וגיא עורכים כל אחד את שלו.

---

## העלאה — פעם אחת

**1. GitHub**

צרו ריפו חדש (Private) והעלו אליו את כל הקבצים מהתיקייה הזו.
אפשר דרך האתר: `Add file → Upload files`, גוררים הכל, `Commit`.

**2. Vercel**

- נכנסים ל-vercel.com ומתחברים עם חשבון GitHub
- `Add New → Project`, בוחרים את הריפו, `Import`
- לא נוגעים בהגדרות, לוחצים `Deploy`

הפריסה הראשונה תעבוד אבל תיפול על טעינת הנתונים — עוד אין מסד. ממשיכים.

**3. מסד נתונים**

בתוך הפרויקט ב-Vercel: `Storage → Create Database → Postgres`.
בוחרים אזור קרוב (Frankfurt), מאשרים, ולוחצים `Connect` לפרויקט.
Vercel מזריק את `POSTGRES_URL` לבד. הטבלה נוצרת אוטומטית בפעם הראשונה שהאתר נטען.

> אם המסך מציע Neon במקום Postgres — זה אותו דבר, אותו משתנה סביבה. אשרו.

**4. מפתח API (אופציונלי)**

בשביל השורות המילוליות בפאנל הניתוח:
`Settings → Environment Variables`, מוסיפים `ANTHROPIC_API_KEY` עם מפתח מ-console.anthropic.com.
בלעדיו הניתוח עדיין מציג את כל המספרים מ-Yahoo, רק בלי הפרשנות.

**5. Redeploy**

`Deployments → … → Redeploy` כדי שהמשתנים ייכנסו לתוקף.

מכאן הכתובת קבועה. שולחים אותה למארק ולרון, כל אחד בוחר את עצמו פעם אחת.

## עדכונים

עורכים קובץ ב-GitHub ושומרים. Vercel בונה מחדש לבד תוך דקה, על אותה כתובת.
אין לינק חדש להפיץ, ואף נתון לא הולך לאיבוד.

---

## מבנה

```
app/page.js              הדשבורד
app/globals.css          העיצוב
app/api/state/route.js   קריאה ושמירה של הנתונים
app/api/quotes/route.js  מחירים חיים דרך yahoo-finance2
app/api/research/route.js פאנל הניתוח
lib/db.js                שכבת המסד
```

הנתונים יושבים בטבלה אחת בשם `kv`, בשתי שורות: `state` (הפוזיציות, ההפקדות, המזומן)
ו-`history` (תצלום שווי יומי לגרף).

## פיתוח מקומי

```bash
npm install
cp .env.example .env.local   # ומדביקים POSTGRES_URL מ-Vercel
npm run dev
```
